# Учёт платежей пользователей

Учебный проект по УП.01.01. WPF-приложение для учёта платежей пользователей с подключением к базе данных Microsoft SQL Server (три таблицы: User, Category, Payment).

## Требования

- Windows, Visual Studio 2022 с компонентом разработки классических приложений .NET.
- .NET Framework 4.7.2 (или совместимая версия), Entity Framework 6.
- SQL Server 2022 и SQL Server Management Studio.
- Microsoft Word и Excel для экспорта отчётов (DOCX/XLSX; PDF при необходимости создаётся через Word).

## Запуск

1. В SSMS подключиться к своему SQL Server и выполнить `db/shema.sql`.\
   Скрипт создаёт базу `DB_Ilamakov_523_Payment`. Существующую рабочую базу он не удаляет — не запускать поверх продакшн-данных.
2. При необходимости выполнить скрипт с тестовыми данными (категории, пользователи, платежи).
3. Открыть решение `UP01_523_Ilamakov_Payment.sln` и восстановить NuGet-пакеты.
4. В `App.config` при необходимости изменить `data source` в строке подключения на имя своего экземпляра SQL Server.
5. Собрать решение и запустить приложение.

Пароли учётных записей хранятся в виде SHA1-хешей. Самостоятельная регистрация создаёт роль «User».

## Возможности и роли

| Роль | Возможности |
| --- | --- |
| **User** (Пользователь) | Просмотр своих платежей, поиск, фильтр по категории, сортировка, смена своего пароля |
| **Admin** (Администратор) | Все платежи: просмотр, поиск, фильтр, добавление, редактирование, удаление; управление категориями; просмотр и редактирование/удаление пользователей; диаграмма по категориям; экспорт в Word и Excel; смена пароля |

Удаление категорий и пользователей выполняется **каскадно**: связанные платежи удаляются вместе с записью (настроено в БД через `ON DELETE CASCADE`).

После трёх неверных попыток входа появляется капча. Перед удалением записей и выходом из приложения запрашивается подтверждение.

Пароли в БД хранятся только в хешированном виде.

## Интерфейс

- Главное окно с `Frame` для навигации между страницами.
- Единый словарь стилей.
- Кнопки одинаковой высоты.
- Динамические заголовки страниц.
- Дата и время в нижней панели главного окна.
- Кнопка «Назад» в верхней панели.

## База данных

Три таблицы:

- **User** — пользователи (Login, Password, Role, FIO, Photo)
- **Category** — категории платежей
- **Payment** — платежи (связь с User и Category)
